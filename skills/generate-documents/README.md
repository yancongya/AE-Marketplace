# Generate Documents Skill

从已有内容生成 AE 脚本文档的技能。

## 概述

本技能帮助你从已有内容快速生成符合规范的文档，支持多种输入类型。

## 支持的输入类型

### 1. 多个文档
- 合并或汇总多个文档
- 识别共同主题
- 生成系列文档

### 2. 项目文件夹
- 扫描项目结构
- 读取 README 和配置文件
- 提取代码注释
- 自动生成文档

### 3. 一篇文章
- 转换为标准格式
- 提取元数据
- 规范化结构

### 4. 一个链接
- 抓取网页内容
- 转换为文档格式
- 提取结构化信息

## 使用方法

### 方式 1：交互式创建

直接调用 skill，系统会通过对话引导你完成文档生成。

### 方式 2：快速模式

提供路径或链接，系统自动生成文档。

## 核心功能

### 智能提取
- 自动提取标题
- 自动提取作者
- 自动提取标签
- 自动生成描述

### 智能整理
- 识别文档类型
- 优化内容结构
- 添加缺失部分

### 规范检查
- 元数据完整性
- 链接有效性
- 格式正确性
- 清单更新

## 工作流程

```
输入类型选择
    ↓
内容提取
    ↓
智能整理
    ↓
生成草稿
    ↓
规范检查
    ↓
交互确认
    ↓
保存文档
```

## 与 writing-documents 的配合

- `generate-documents`：从已有内容生成
- `writing-documents`：从零开始创建

可以配合使用：
1. 使用 `generate-documents` 生成草稿
2. 使用 `writing-documents` 进行规范检查
