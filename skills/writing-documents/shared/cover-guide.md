# 封面使用指南

## 概述

封面图片是展示文章内容的重要视觉元素，支持自定义封面和自动生成封面两种方式。

## 封面优先级

系统按以下优先级显示封面：

1. **自定义封面** (`coverImage`)：用户提供的图片 URL
2. **自动生成封面**：基于标题和描述动态生成
3. **占位符**：显示 `[ No Cover ]` 占位符

## 自定义封面

### 格式要求

- **尺寸**：建议 16:9 比例（如 1280×720）
- **格式**：JPG、PNG、GIF、WebP
- **大小**：建议不超过 2MB
- **清晰度**：建议 720p 或更高

### 使用方法

在文档的 YAML frontmatter 中添加 `coverImage` 字段：

```yaml
---
title: 我的文档
author: 烟囱鸭
tags: [示例, 封面]
description: 这是一个示例文档
updatedAt: 2026-03-19
isFavorite: false
coverImage: https://example.com/cover.jpg
---

# 文档内容
```

### 图片来源

**推荐来源**：
- GitHub 仓库：`https://github.com/owner/repo/raw/main/path/to/image.jpg`
- 图片托管服务：Imgur、Cloudinary 等
- CDN：AWS CloudFront、Cloudflare 等

**注意事项**：
- ✅ 使用稳定的图片 URL
- ✅ 确保图片可以公开访问
- ✅ 使用 HTTPS 协议
- ❌ 避免使用临时链接

## 自动生成封面

如果未设置 `coverImage`，系统会自动生成默认封面。

### 生成规则

**尺寸**：640×360（16:9 比例）

**设计风格**：
- 背景：蓝色渐变（#1e3a5f → #0d1b2a）
- 网格线：半透明白色线条
- 边框：白色半透明边框
- 文字：白色等宽字体

**内容显示**：
- **标题**：居中显示，粗体，36px
- **描述**：标题下方显示，24px，70% 透明度

### 文字限制

- **标题**：最多 25 个字符（超出显示 `...`）
- **描述**：最多 40 个字符（超出显示 `...`）

### 示例效果

```yaml
---
title: "我的脚本"
description: "功能强大的自动化工具"
---

# 无 coverImage，自动生成封面
```

生成的封面会显示：
```
┌────────────────────────┐
│  我的脚本               │
│  功能强大的自动化工具    │
└────────────────────────┘
```

## 封面显示效果

### 卡片显示

封面会显示在文章卡片的顶部，占整个卡片宽度的 16:9 区域：

```
┌─────────────────────┐
│ [封面图片区域]       │ ← 16:9 比例
├─────────────────────┤
│ 标题                │
│ 描述                │
│ 标签                │
└─────────────────────┘
```

### 悬停效果

- 图片轻微放大（scale 1.05）
- 过渡动画（0.3s ease）
- 边框高亮

### 响应式

- 移动端：自适应宽度
- 桌面端：固定比例，保持清晰

## 收藏与封面

**收藏状态**不影响封面显示：
- ✅ 收藏文章：显示星星图标 + 封面
- ✅ 非收藏文章：只显示封面

**封面优先级独立于收藏状态**

## 最佳实践

### 1. 封面设计

**建议**：
- 使用高质量的图片
- 确保文字可读性（如果封面包含文字）
- 保持简洁，避免过多元素
- 使用与主题相关的图片

### 2. 图片优化

**建议**：
- 压缩图片大小
- 使用 WebP 格式（现代浏览器支持）
- 启用懒加载（自动支持）
- 使用 CDN 加速

### 3. SEO 优化

**建议**：
- 使用有意义的文件名
- 添加 alt 属性（自动使用标题）
- 确保图片可访问性

### 4. 一致性

**建议**：
- 同类文章使用相似风格的封面
- 保持品牌识别度
- 定期更新封面以保持新鲜感

## 故障排除

### 封面不显示

**可能原因**：
1. 图片 URL 错误或无法访问
2. 图片格式不支持
3. 网络问题

**解决方案**：
- 检查图片 URL 是否正确
- 确保图片可以公开访问
- 尝试使用其他图片托管服务

### 封面模糊

**可能原因**：
1. 图片分辨率过低
2. 图片压缩过度

**解决方案**：
- 使用更高分辨率的图片
- 减少压缩程度
- 优化图片质量

### 封面加载慢

**可能原因**：
1. 图片文件过大
2. 图片服务器速度慢

**解决方案**：
- 压缩图片大小
- 使用 CDN
- 使用更快的图片托管服务
