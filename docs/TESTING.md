## 测试步骤

1. **启动开发服务器**
   ```bash
   npm run dev
   ```

2. **访问各个tab页面**
   - http://localhost:5173/expressions
   - http://localhost:5173/scripts
   - http://localhost:5173/presets
   - http://localhost:5173/extensions

3. **测试新文档**
   - 在各个tab中找到新创建的文档
   - 点击进入详情页

4. **测试Mermaid图表**
   - 滚动到各个图表位置
   - 测试全屏功能
   - 测试缩放功能（滚轮和按钮）
   - 测试复制功能
   - 切换主题查看效果

5. **测试代码块**
   - 查看语法高亮效果
   - 测试行号显示
   - 测试复制功能和Toast提示
   - 测试横向滚动
   - 切换主题查看效果

6. **测试目录**
   - 点击目录项测试跳转
   - 滚动页面测试高亮
   - 测试移动端浮动按钮
   - 切换主题测试兼容性

7. **测试终端组件**
   - 查看 `$` 符号显示
   - 验证文本格式
