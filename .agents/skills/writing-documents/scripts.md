# 脚本文档编写

## 核心要素

### 1. 下载链接（必须）

使用网络地址，包含文件信息。

```markdown
🔗 [下载脚本](https://github.com/.../script.jsx)

**文件信息：**
- 文件大小：1.2 MB
- 版本：v1.0.0
- 兼容性：AE CC 2019+
```

### 2. 使用场景（推荐）

列举 3-5 个典型应用场景。

### 3. 功能特性（推荐）

列出主要功能和快捷键。

### 4. 原理分析（可选）

解释脚本架构和关键函数。

### 5. 使用教程（推荐）

安装、运行、配置步骤。

### 6. 常见问题（可选）

FAQ 部分。
